$ mouser

A fast GPU terminal emulator, written in Rust.

Mouser runs your login shell in a PTY, parses VT/xterm escape sequences and renders the grid on the GPU. Linux first.

Install View on GitHub

Features

  • GPU rendering

    wgpu renderer with a CPU fallback (MOUSER_RENDERER=cpu).

  • Tabs

    Each tab has its own PTY, screen, scrollback and title. Connections open in new tabs.

  • Connection manager

    Sidebar for SSH hosts from your ssh config, plus Waypipe, tunnels and X11.

  • Compressed scrollback

    Chunked history compressed with Zstd or LZ4 when idle, searchable across compressed chunks.

  • Fuzzball protocol

    Mouser's own open graphics and keyboard protocol. Read the spec. Kitty keyboard/graphics and iTerm2 OSC 1337 images stay supported as a fallback.

  • Modern xterm

    Truecolour, curly and coloured underlines, wide characters, mouse, focus, bracketed paste, OSC 8 links and OSC 52.

  • Red Star theme

    Dark and light Red Star themes by default, following the system mode.

  • TOML config

    Font, colours, scrollback size, compression algorithm and level, and idle thresholds.

Install

Homebrew (macOS)

# CLI
brew install --formula https://raw.githubusercontent.com/m3talsmith/mouser/main/Formula/mouser.rb
# App
brew install --cask https://raw.githubusercontent.com/m3talsmith/mouser/main/Casks/mouser.rb

From source with cargo

git clone https://github.com/m3talsmith/mouser
cd mouser
cargo run -p mouser-app --release

GitHub Releases

Each release ships:

  • Linux: .deb, .rpm, Arch mouser-bin
  • macOS: Mouser.app .dmg
  • Windows: portable .zip and installer .exe

Optional terminfo entry: tic -x -o ~/.terminfo extra/mouser.terminfo

Quick start

Launch Mouser and your login shell starts in the first tab. Open the sidebar to add or pick an SSH host; clicking it opens ssh <alias> in a new tab.
