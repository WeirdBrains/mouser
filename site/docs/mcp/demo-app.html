Demo app: a Flutter client for Mouser's MCP server

The Mouser MCP demo is a Flutter app that talks to Mouser's MCP server and exercises every tool it offers. It's a worked example of integrating with the server from your own app.

What it covers

  • Tools only. The app uses MCP's initialize, ping, tools/list and tools/call. It doesn't use resources or prompts.
  • Transports. HTTP with MCP sessions, HTTPS with either a pinned certificate or a CA, and stdio through mouser mcp serve --stdio.
  • All 11 tools: tabs_list, screen_read, scrollback_read, shell_type, shell_run, files_list, files_read, files_mkdir, files_copy, files_move and files_trash.

Walkthrough

The app has four pages.

1. Connect

Pick a transport and connect. Turn the server on first, as described in Mouser and MCP: HTTP is http://127.0.0.1:7801/mcp, HTTPS is https://127.0.0.1:7802/mcp, where you either trust $MOUSER_HOME/mcp/cert.pem or pin the SHA256 that mouser mcp status shows. For stdio, the app starts mouser mcp serve --stdio, which bridges to the running Mouser and reads the token itself. Over HTTP and HTTPS the app needs the token from mouser mcp token --show.
