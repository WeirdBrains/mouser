Mouser handover notes

Repository: https://github.com/WeirdBrains/mouser (moved from m3talsmith/mouser on 2026-10-31). Current release: v1.3.0 (2026-11-04). Homebrew formula/cask are updated automatically by the Release workflow. CI covers Linux, macOS and Windows.

Public notes for whoever picks up Mouser next. Machine-specific paths, local branch/worktree state and other private context live in HANDOVER.local.md at the repo root (gitignored; ask the maintainer if you don't have it).

Fuzzball

Spec v0.1 with resolved decisions in fuzzball docs/README.md §10. OSC 1337 and xterm-kitty were removed. Kitty keyboard and Kitty graphics are fallbacks; Fuzzball takes precedence. Placements follow their text (scroll regions, IL/DL, scrollback, resize) and are removed when their anchor row leaves the scrollback; abandoned uploads expire on a timer (Session::watch_graphics in crates/mouser-app/src/tabs.rs, which also plays Kitty animations and is kicked through a condvar when new timer work arrives). Resize scales placements to the screen width, shrinking in place (Placement::fit, requested col/cols/rows kept) and ImageScaler caches area-averaged downscales for both renderers. Decisions: protocol README §10 #10–15. mouser show (crates/mouser-app/src/show.rs, tested in crates/mouser-app/tests/show_tests.rs) displays images: Fuzzball first, Kitty fallback, Kitty Unicode placeholders inside tmux (README §10 #19-20).

Release process (see AGENTS.md)

  1. Bump version and update CHANGELOG.
  2. Commit release: vX.Y.Z, create an annotated tag vX.Y.Z.
  3. git push origin main --follow-tags.
  4. Check CI with gh run list / gh run watch. Releases happen only with the maintainer's explicit approval.

Rules

  • Work on main, no PRs/branches (exception: site for the website).
  • cargo fmt --all --check, cargo clippy --workspace --all-targets -- -D warnings and cargo test --workspace must pass.
  • Never touch the real ~/.mouser; never force-push; ask before adding dependencies.
  • Tests use MOUSER_SSH_CONFIG and a temp HOME, never the real ~/.ssh.

Packaging

CI may only use GitHub-owned or verified actions (WeirdBrains org policy); any other action fails the run at startup with no jobs. The workflows install Rust with rustup, cache with actions/cache and publish with gh release create (2737875); the release path is untested until the next tag. Arch: packaging/arch/mouser-git (source) and packaging/arch/mouser-bin (release binary) PKGBUILDs with .SRCINFO; details and AUR steps in docs/release.md. Both conflict with each other and replace older mouser-bin installs. The release workflow builds the mouser-bin .pkg.tar.zst and then commits real checksums via packaging/arch/update-bin.sh. AUR publishing waits: registration is closed and it needs the maintainer's account; the repo also needs a LICENSE file first (namcap error). All URLs now point at WeirdBrains/mouser; the app ID io.github.m3talsmith.mouser stays unless the maintainer decides otherwise.

P2: Mouser's MCP server (docs/mcp.md)

  • 7006d97 (core):
  • mcp_server.rs: JSON-RPC MCP over Streamable HTTP. It is written on std (no tokio; rmcp not needed), with JSON replies and no SSE; sessions are keyed by Mcp-Session-Id, so the server knows each client's name. Checks: Bearer token compared in constant time, Host/Origin loopback, 4 MiB body cap, 32 connections at most.
  • TLS is rustls with ring (no aws-lc, so no cmake). The self-signed cert is made by rcgen in $MOUSER_HOME/mcp/{cert,key}.pem (key 0600), or the user's PEM pair is used. stdio_bridge and the post/client_tls test client are here too.
  • secrets.rs: keyring 3 (Keychain / Credential Manager / Secret Service over zbus, so no libdbus). The account is name@hash(MOUSER_HOME). Fallback is a $MOUSER_HOME/secrets/<name> 0600 file; MOUSER_SECRET_STORE=file forces it, and every test uses that.
  • fileops.rs: list, read, mkdir, copy, move, trash (to $MOUSER_HOME/trash).
