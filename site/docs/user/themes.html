Theming

Themes control font size/family, colors, and a light/dark/system mode (default: system, follows OS). In system mode Mouser reads the desktop colour-scheme preference (GNOME/freedesktop color-scheme, macOS AppleInterfaceStyle); if the desktop does not explicitly prefer light, the dark variant is used. MOUSER_SYSTEM_DARK=1|0 overrides detection.

Switching

  • Sidebar → Appearance, or :theme, opens the switcher: built-in themes first, then user themes found in ~/.mouser/themes/, plus dark/light/system mode. Moving the selection previews live; Apply saves theme/mode to preferences.toml. :theme <name> and :mode <m> do the same directly.
  • Mode buttons size to their labels (Unicode width). In a narrow window they shrink padding, then abbreviate to d / l / sys — they never chop mid-word (dar, ligh).

Editing

  • Edit colours & font in the switcher (or :edit-theme) edits the active variant: foreground, background, cursor, accent and the 16-colour palette as hex (#rrggbb or #rgb) with swatches, plus font family and size. Valid edits preview live; invalid fields are outlined in red.
  • Save writes ~/.mouser/themes/<Theme>/<variant>.toml and the font to preferences.toml.
  • Theme files may contain cursor, accent and palette = [16 colours]; all are optional.

Accuracy

  • Palettes are sourced from each theme’s canonical definitions (foreground/background primaries).

Storage

  • Themes live under ~/.mouser/themes/<ThemeName>/{dark.toml,light.toml} (override with MOUSER_HOME).
  • Built-ins are written on first run; editing copies from built-ins.

Mode and resolution

  • Preferences select theme and mode (light/dark/system). For tests, system mode is simulated via MOUSER_SYSTEM_DARK=1.

Font picker

Clicking (or tabbing to) the editor's Font family field — or running :font with no argument — opens a list of the font families installed on the system, in name order. Typing fuzzy-filters it (case-insensitive subsequence; matched letters are highlighted) while the list stays alphabetical. ↑/↓ or the mouse wheel move, Enter or a click picks (the font then loads in the background), and Esc or a click elsewhere closes the list. Families are discovered once, on a background thread, at startup; typing only filters.
